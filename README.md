# Snake Game

This is a simple Snake game implemented in JavaScript. The player controls a green snake that eats red fruits, growing longer and moving faster as it eats. The game is played using the arrow keys for control.

## Project Structure

```
snake-game
├── src
│   ├── index.html       # HTML structure for the game
│   ├── script.js        # JavaScript code for game logic
│   └── style.css        # CSS styles for the game
├── package.json         # Project metadata and dependencies
└── README.md            # Documentation for the project
```

## How to Play

1. Use the arrow keys to control the direction of the snake.
2. Eat the red fruits to grow longer and increase your speed.
3. Avoid colliding with the walls or the snake itself.

## Setup Instructions

1. Clone the repository to your local machine.
2. Navigate to the project directory.
3. Open `src/index.html` in your web browser to start playing.
